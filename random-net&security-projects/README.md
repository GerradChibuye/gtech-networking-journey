# Networking Random Projects

## Overview

This repository contains practical networking projects, experiments, and simulations created while exploring different concepts in networking, cybersecurity, and infrastructure.

The goal of this repository is to document hands-on learning through real configurations, troubleshooting exercises, and network simulations rather than only studying theory.

Each project focuses on a specific networking or security concept and includes documentation explaining:

- The problem being explored
- The network design
- Technologies and concepts involved
- Configuration steps
- Testing and observations
- Lessons learned

---

# Purpose

Networking is best learned by building, breaking, troubleshooting, and improving systems.

This repository serves as a practical knowledge base where I document experiments involving:

- Network design
- IP addressing and subnetting
- Routing
- Switching
- Network security
- Protocol analysis
- Infrastructure concepts
- Cybersecurity fundamentals

The projects here represent continuous learning and experimentation as I develop deeper skills in networking and infrastructure engineering.

# Repository Structure
